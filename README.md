# TechCrop

TechCrop is an innovative application designed to empower farmers with digital financial solutions. The platform provides tools for farmers to track farm performance, improve credit scores, and access timely financial support for sustainable growth.

It offers two main access methods:

- **USSD Interface**: For accessing basic features on any phone, even without internet access.
- **Web Portal**: A feature-rich platform for farmers and administrators with internet access.

## Features (Partial List)

- **Credit Scoring**: Analyze farming history, income, and other factors to generate a credit score.
- **Loan Applications**: Apply for loans based on credit score, track status, and submit documents.
- **Repayment & Monitoring**: Manage repayments and monitor loan status and credit score improvements.

## Setup and Installation

To get the project up and running locally, follow these steps:

1.  **Clone the repository:**

    ```bash
    git clone <repository-url>
    ```

    Replace `<repository-url>` with the actual URL of your repository.

2.  **Navigate to the project directory:**

    ```bash
    cd tech-crop
    ```

3.  **Install dependencies:**

    Using Yarn:
    ```bash
    yarn install
    ```
    Or using npm:
    ```bash
    npm install
    ```

4.  **Run the development server:**

    Using Yarn:
    ```bash
    yarn dev
    ```
    Or using npm:
    ```bash
    npm run dev
    ```

    The application should now be running at `http://localhost:5173/` (or another port indicated in your terminal).
